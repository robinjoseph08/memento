# Domain docs

Memento is a single-context repository.

## Before working

- Read `CONTEXT.md` and use its canonical domain terms.
- Read relevant decisions under `docs/adr/`.
- If either location is absent, proceed without suggesting placeholder documents.

## Vocabulary

Use the glossary's preferred terms in issues, tests, implementation, and documentation. Do not introduce synonyms listed under `_Avoid_`.

## Architectural decisions

Surface any proposed change that conflicts with an existing ADR. Do not silently override an accepted decision.
