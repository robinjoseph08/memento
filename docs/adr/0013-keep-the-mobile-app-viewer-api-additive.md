# Keep the Mobile App's viewer API additive

The Mobile App will ship through app stores and talk to Installations that operators upgrade on their own schedule, so any app version can meet any server version. Memento will treat the viewer endpoints the Mobile App calls as a stable contract. Fields and endpoints may be added, but never renamed, removed, or changed in meaning. Go tests will pin the JSON shape of each contract endpoint so a breaking change fails CI, the public status endpoint will report the server version, and the app will make one minimum-version check that asks the Person to have their Memento updated. Memento will not version routes or publish an OpenAPI spec with generated clients, because about a dozen endpoints with Tygo-generated types do not justify either. Curator endpoints stay outside the contract and keep changing freely with the embedded web app.
