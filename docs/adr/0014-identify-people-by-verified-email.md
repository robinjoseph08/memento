# Identify People by verified email

Memento identifies a Person by the email addresses they have proven they control, not by an identity provider's subject. Google sign-in and emailed Sign-in Codes are two ways to verify the same Linked Email, so both admit the same Person through the same Preauthorization and Access Request rules, and an operator can run an Installation with no Google client at all. The cost is that a Google account whose address changes looks like a new, unknown email, which matches what Curators already assume when they preauthorize an address.
