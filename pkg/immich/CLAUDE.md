# Immich Adapter Contract

- This package is Memento's server-side adapter for the pinned Immich version and least-privilege operation set. Browsers never call Immich or receive its credentials, direct URLs, or raw DTOs. Recipient contracts expose no Immich IDs, paths, or face coordinates; Curator repair contracts may expose only the explicitly normalized evidence required for manual repair.
- Normalize dependency responses into narrow Memento types. Every supported provider operation uses a private named request or response DTO declared in this package with typed presence and nullability. Pass request DTO values directly through `doJSON`, `doJSONStatus`, or `marshalJSONRequest`; local JSON serialization away from those provider seams remains permitted. Call protected JSON client functions, compatible local interfaces, and direct wrappers in place, and never pass, store, or return them as function values. Response roots may use slice or array containers only when every root leaf is a private named struct declared in this package. Every JSON-reachable DTO field must use typed local contract objects or scalar and standard serialized value leaves, never anonymous structs, maps, or interfaces. The contract gate rejects anonymous, map, interface, scalar, external, raw byte, and unresolved response leaves, rejects exported or otherwise invalid request roots, and semantically rejects `json.RawMessage` fields in DTOs reachable from provider request or response roots. Fail closed on missing or null required fields, duplicate or case-colliding members, invalid identities, bounds, pagination, content types, or response sizes.
- Return only safe classified errors. Never include keys, headers, upstream bodies, URLs, paths, or unnormalized provider data in errors, logs, health, or worker diagnostics.
- For Media, validate Range and cache validators, allowlist statuses and response headers, bound derivatives, and stream videos and originals. Callers own and must close returned bodies. Keep metadata deadlines and streaming header timers independently controllable in tests so cancellation is deterministic without imposing a whole-stream timeout.
- Follow only a bounded number of same-origin redirects. Reject cross-origin, credential-bearing, non-HTTP, or otherwise unsafe targets before forwarding credentials.
- Keep hermetic malformed and adversarial tests, fuzz parsing surfaces, and the live pinned contract suite. Supporting a later Immich release requires changing the pin and passing the complete contract rather than widening acceptance speculatively.
- Prove the production `assetPageSize` in the live pinned contract with metadata-only `asset` and `album_asset` rows seeded directly against the pinned schema. Seed only after the API creates the user, album, and representative Media parents. Use unique deterministic identities, timestamps, checksums, and synthetic paths, create no derivative jobs, and make schema drift fail visibly.
- Keep live contract assertion diagnostics to fixed stages, status codes, counts, and safe classified adapter errors. Never print credentials, fixture source paths, upstream bodies, request URLs, email addresses, provider identities, or provider Media bytes.
